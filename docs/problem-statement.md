# FolderWalk problem statement

FolderWalk is a small public Rust terminal application for a university
student learning Rust. It shows the full path of the current directory and
lists its contents. The student can navigate with the keyboard or go
directly to a directory by typing or pasting a path. While the student edits
that path, the current path and listing stay visible and steady.

The source and public README are written for students to study. FolderWalk
is the first workspace to exercise all five Rust standards plugins together.

Exact key bindings, path and symlink behavior, error handling, and the
parent shell's directory on exit are design decisions.
