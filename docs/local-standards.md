# Local Rust standards setup

The five Rust standards plugins are listed in [the agent instructions](../AGENTS.md).
The paths there describe the local test installation. On another machine,
use the locations from your own Rust standards marketplace or installation.

For Codex, follow the local marketplace and plugin installation instructions
in each plugin's README. Start a new session after installing the plugins.
If marketplace registration is blocked, read the shared skills directly
from the Rust standards checkout and run their applicable commands from
the FolderWalk root.

Record package discovery, native loading, and checks run in FolderWalk
separately. See the [standards results](standards-results.md) for this run.
